## 图表如何适配

### 二维取舍图

画布使用蓝白粉渐变、顶部反光带、渐变边缘和细网格；外层是独立的玻璃底板。方案点使用径向渐变做玻璃珠高光；选择光环、四维非劣环、字母及名称仍保留。坐标固定为 0–100，点中心不因材质或角色发生偏移。违规 B 使用空心虚线圆与文字提示。高光不是新的数据维度。

**ECharts 映射：**保留 scatter 数据与坐标设置；`itemStyle.color` 可用 `echarts.graphic.RadialGradient`，边线用方案色。轴文字用辅助文字色；`splitLine` 用 #cdd8eb。绘制高光即可，避免对 canvas 使用会扭曲坐标的 SVG 位移滤镜。非劣环读取完整四维返回结果。

### 双方案差值图

每个维度有浅色圆角底带，两个玻璃端点以半透明渐变连线连接，细白线形成反光。数值紧邻真实端点；重合分数显示双层圆；右侧正负差值及小结保持深色。渐变表示两个方案的连线，不是另一种评分尺度。

**ECharts 映射：**使用现有 custom 系列或 scatter + 连接线；端点的径向渐变与取舍图一致，连线线宽约 10px、透明度约 55%。先画底层连线，再画端点和标签。差值继续从原始分数计算。

### 指标 / 合规工作台

V6 将表格内部改成有间隔的二维卡片网格。表头是方案卡片，显示字母、完整名称、排名与贴近度；每格使用白色亮边、圆角和轻高光。四个维度汇总格带方案浅色，展开的指标格更轻，左侧以竖线区分明细层级。固定表头和首列底层保持不透明，防止滚动内容穿透；格子自身不叠加模糊滤镜。

进度条颜色沿用方案身份，长度仍表示 0–100 分；颜色不代表高低，数字是主要读数。分差模式保留中线，负差为琥珀色。B 列用粉色斜纹和表头“未通过 / 仅参考”提示；选中格和对应表头以方案色描边；缺数据不填成零。合规状态分别使用通过、未通过、不适用和数据不足的文字胶囊。

网格最小宽度 735px，窄屏在表格内部横向滚动。默认五方案、七行结果仍能完整放入当前高度；筛选与全部展开继续沿用原有行为。导出 SVG 使用同样的卡片表头、分数格、进度条和参考列斜纹；每格的分数与差值仍从相同数据生成。

**Ant Design 映射：**在 Table 容器上使用玻璃圆角，固定层保持不透明，选中样式绑定现有选择状态；详情延续 TraceDrawer。按钮、分段切换、搜索、焦点反馈按原组件能力接入，避免把过滤器包裹成多层 backdrop-filter。

内部样式映射：通过 `onCell` 或列 render 提供 scheme_id 对应的颜色变量；格子采用 `border-radius:12px` 与白色细边；表头 render 为字母标识 + 名称 + 排名卡片。保留语义表格，不把每套方案拆成无法横向对齐的独立表格。详见 [总表前后对照](evidence/comparison-matrix-before-after.png) 和 [总表入口](prototype/comparison.html#view=matrix)。

## 动效、降级与验收

- 背景静止，无持续动画；沿用短时透明度反馈与减少动态效果设置。
- 不支持 backdrop-filter 时用实底；`prefers-reduced-transparency` 时取消玻璃模糊。这是渐进增强，浏览器是否支持该媒体特性取决于实际版本。
- 导出图自带静态柔光背景和 SVG 渐变，不依赖网页 CSS、远程字体或浏览器的 backdrop-filter。
- Edge 实机无界面验收：三种视图、角色切换、搜索、筛选、基准差值、键盘焦点、合规/缺值、导出失败与重试，以及 320 / 375 / 414 / 768px 布局与抽屉。五种 SVG 完成下载和 XML 解析检查。
- 当前没有引入第三方运行依赖，也没有使用真正的背景位移折射。未来若试点真实折射，建议限于小面积导航胶囊，在目标浏览器单独检查。

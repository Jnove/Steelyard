## PR #10：54 条内建规则

接入施工安全、基础、钢结构及构件规则，同时保留现有正式对比看板。集成审核修正了以下输入与规则之间的冲突，没有改写条文数值：

- 基础、混凝土内支撑、错层处构件分别使用专用混凝土等级；错层处平面外受力墙使用专用厚度。不能用上部结构等级或普通墙厚证明局部构件通过。
- 两墙合一地下连续墙、错层处平面外受力墙采用可空的专业声明，未核对保持数据不足。
- 钢结构单跨框架规则限定框架体系；结构高层 / 多层分类由专业组明确输入，不以住宅消防高度分界自动替代。
- S-26 埋深建议使用 warning，不因建议值未满足直接排除排名。

新增输入均可空，没有迁移或补造旧项目的工程参数。引擎仍按表达式引用字段检查缺失，不做条件短路推断；所需适用声明未填时可能显示数据不足。规则数量与覆盖率不等于工程合规证明。

## PR #12：运行期自定义覆盖层

提供数据库中的自定义字段、开放候选项、规则、角色模板、审计与回灌导出。集成时审核实际求值、类型校验、嵌套字段录入、删除依赖及缓存失效，而非只核对接口是否存在。

本能力是地区规则的基础设施。地区配置、规范版本选择和专业适用性核定仍需后续实现；不能将自定义来源字符串视作出处已核验。生产写入口继续关闭，操作者头仍为开发占位。自定义内容不进入构建期 Schema 或离线快照。

集成修复包含：显式注册字段白名单贯穿规则求值；CRUD、Excel、What-if 与评估共同校验类型及取值；规则回读和 Agent 解释使用完整规则集；规则 / 字段变更在业务和审计同一事务中使旧评估、排名证据与报告失效；禁止删除仍被规则引用的字段。自定义内容当前全局生效。

评估 JSON 保存规则与字段语义签名。旧结果没有签名，或规则定义已改变时，读取评估、排序及 Agent 证据返回 409，要求重新评估；不会按新规则重新标注旧分数。无需增加数据库列，旧 SQLite 只创建新增表，原输入不被改写。

表单与参数对照读取、提交 `params.custom`；编辑保留未改变的历史未注册值，但不会将其作为有效规则输入。超范围比例、布尔冒充数字、未知键及内建名覆盖均拒绝。超限不规则项保持封闭清单，避免候选注册成功但模型拒收。

回灌导出对 Python 字符串安全转义；拒绝关键字、保留编号和歧义角色名。新增只读动态 Excel 模板与项目方案导出入口，支持当前注册字段。默认导入仍整文件拒绝，错误以中文汇总。

Excel 隐藏保留容器，只导出独立自定义字段，避免两份输入相互覆盖；名称、标签及以 `=` 开头的文本作为原文保存。通用数值回灌不擅自增加正数限制，列表与严格类型校验须随字段一起迁移。

# 筑衡青绿与紫粉玻璃界面方案

日期：2026-10-12。实现基线：`bae0492`。本轮在 `jnove/liquid-glass-ui` 隔离分支实现，完成后经本地验收交付；`main` push 会自动部署，本轮不自动发布。

## 已确定的方向

采用用户选中的“漂浮展台”构图：左侧大标题与真实操作入口，右侧可切换的建筑体量展示。风格比原工程工作台更鲜明，目标是让初次访问者马上感受到建筑方案比选的主题，并能进入现有功能。

- 左上光晕使用 **`#1BE49A` 青绿**，右下使用 **`#C8A7DD` 紫粉**，中部保留近白底。颜色是用户指定值；透明度与扩散范围通过实际页面调整。
- 强化透明玻璃的悬浮感：透过面板能看到背景色晕，边缘有窄高光，近处有接触阴影，远处有柔和投影；光晕、玻璃和正文具有清楚的前后层次。
- 右侧首屏使用 Three.js 建筑体量场景，支持方案切换与有限拖动观察。它是参数驱动的概念示意，不是 BIM、工程模型或安全分析结果。
- 保留当前 React 18、TypeScript、Vite、Ant Design、ECharts，以及项目、方案、看板、对话路由和 REST / SSE 协议。

## 视觉系统

| 层次 | 实现方向 |
| --- | --- |
| 背景 | 两个 radial-gradient 固定于视口角落，边缘较浓、向中央散开；允许少量色彩渗入玻璃。通过根节点透明背景避免被原白底遮住。 |
| 顶部导航 | 悬浮圆角玻璃条，与页面边缘留出空间；背景填充约 16–32%，局部渐变高光、细亮边、两层投影；blur 约 16–24px。 |
| 展台浮层 | 比导航更通透，圆角约 24–30px；展示实际方案名称、已有参数或简短操作，不放虚构评分。确保文字位于稳定底色区域。 |
| 内容面板 | 表格、图表、表单与报告使用更厚的浅色材质；玻璃边缘保持统一，减少透背景对数据的干扰。 |
| 操作与文字 | 深色正文，青绿只用于少量高光；主要按钮使用深色底或深青绿，避免亮绿底上的浅字。中文采用本地系统字体，标题与正文通过字重和尺度区分。 |
| 动效 | 首屏一次入场、控件短过渡、方案切换时体量平滑变换；拖动场景有明确反馈。尊重减少动态效果设置，背景不持续漂移。 |

颜色、材质、圆角与阴影集中在 `frontend/src/theme.ts` 和注入的 CSS 变量中。新增样式文件使用这些变量，避免组件各自定义颜色。Ant Design 的下拉、弹窗、抽屉与提示层保持足够实底和正确层级。

## 页面与交互

1. **项目总览**：首屏为漂浮展台，标题说明建筑方案比选；“体验当前项目 / 示例”和“新建项目”接现有真实路由与表单。原项目列表、错误、加载、空状态和 CRUD 继续可用。示例标识来自实际项目上下文，不把任意项目编号默认为虚构案例。
2. **方案录入**：统一卡片、分组与表单材质，保留单位、校验、Excel 导入、编辑和评估操作。
3. **对比看板**：结论与角色选择仍使用实际评估和排名；详细图表、参数依据与追溯抽屉保持可操作，真实并列或未换位结果如实展示。
4. **对话与报告**：阅读区使用稳定浅底，输入工具条使用玻璃；保留 SSE、取消、最终正文替换、引用与 Markdown 下载。

## Three.js 首屏场景

- 优先使用原生 `three` 与 TypeScript 类型，单独组件并懒加载，不额外引入 React Three Fiber 或大型动效框架。
- 获取当前展示项目的真实 `schemes.list(projectId)`。体量使用已有楼栋数、层数等参数进行有上限的概念映射；数据不足时显示明确空态或“概念示意”，不补造工程参数。
- 使用基础几何体、柔光、透明台座和适度物理材质；不下载外部建筑模型、HDR 或纹理。场景颜色引用统一设计 Token。
- 方案按钮使用真实 ID 与名称。切换改变相应体量形态，点击或拖动仅影响展示，不修改方案数据、评估、权重或排名。
- 可拖动有限角度，提供键盘可用的方案选择；画布外保留名称、关键参数和说明。明确“参数体量示意，不含真实空间布局”。
- 限制像素比与几何体数量，只在交互或过渡期间渲染；离屏、页面隐藏与卸载时停止帧循环。卸载时清理监听器、观察器、geometry、material、texture 和 renderer。
- WebGL 不可用、上下文丢失或懒加载失败时，降级为可操作的静态体量图与文字。移动端降低画布负担，减少动态设置下保留静态展示与直接切换。

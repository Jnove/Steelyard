# 真实地块对比样例清单：公租房项目

> 本文件汇总**可公开查证的真实公租房项目**，作为方案对比演示的样例池：
> 同一个系统、同一套规则，换一个真实项目再跑一遍。
> 每条都注明来源与「已核实 / 待核实」的字段——**只收能查到出处的东西**，
> 不要凭记忆补数（这是本项目 [不变的约束](../../memory/README.md) 的一部分）。
>
> 最后更新：2026-10-13。数量、金额、日期以来源原文为准，引用前请再点开核对一次。

---

## 一、怎么用这份清单

1. 三个项目**全部保留**，用途是对比，不是「三选一」：同一个规则集下换项目重跑，
   看结论哪些稳定、哪些随项目条件改变。横向对照见第三节。
2. 已落地为可运行案例的是**前进公租房一期**（`data/schemes/qiantang-real/`）；
   另外两个按同一目录结构复制即可，只需改 `project.json` 的字段。
3. 项目层用公开值，方案层（楼栋数、层数、户型、装配率）自拟并标注「演示自拟」。
4. 每次改完用 `scripts/check_demo_case.py` 跑一遍，确认没有越线、没有零分维度。
5. 对外材料必须同时写清「项目层来源」与「方案层为演示数据」两句话。

## 三、三个公租房项目的横向对比（对比用）

> **用途说明**：本清单是为**方案对比演示**准备的样例池——同一个系统、同一个规则集，
> 换一个真实项目再跑一遍，用来证明「结论不是为某一个案例定制出来的」。
> 因此三个项目**全部保留**，不挑「最好用的一个」。`data/schemes/qiantang-real/`
> 已按前进一期落地为可运行案例；另外两个按需复制同结构即可。

| 对比项 | 前进公租房一期 | 下沙公租房一期 | 临平东湖北路公租房 |
| --- | --- | --- | --- |
| 行政区 | 钱塘区 | 钱塘区 | 临平区 |
| 用地面积 | **43,117 m²**（规划许可申报口径） | 25,577 m²（划拨宗地） | 24,911 m² |
| 总建筑面积 | **183,275 m²**（地上 107,749 + 地下 75,526） | 未公开（调整公示只给了增量 240.68 m²） | 未公开 |
| 套数 | 1,572 户（竣工验收）／1684 套（现场报道） | 1,114 套 | 未公开 |
| 户型面积 | **55–66 m²** | 未公开 | 未公开 |
| 容积率 | **2.50**（批准地上面积 / 用地面积，推定） | 未公开 | **2.0–2.5**（规划条件） |
| 建筑密度上限 | 未公开（本案例暂取 0.22） | 未公开 | **≤ 22%** |
| 绿地率 | **35%**（竣工验收稿） | 未公开 | **≥ 35%** |
| 建筑限高 | 未公开（25 层，本案例暂取 80 m） | 未公开 | **≤ 54 m** |
| 楼栋构成 | **10 栋：4×24 层 + 6×25 层** | 8 栋（全部结顶） | 未公开 |
| 抗震设防烈度 | **6 度（0.05g）** | **6 度（0.05g）** | **7 度（0.10g）** |
| 出处硬度 | **规划许可双证号**（地字第330114202200045号、建字第330114202200066号）+ 发改/EPC 信息 | **划拨决定书文号** 杭规划资源（钱）字〔2022〕021号 | 规划条件公示（四项指标齐全） |
| 案例现状 | 已落地：`data/schemes/qiantang-real/` | 待建：复制同结构 | 待建：需把 `seismic_intensity` 改为 `7度(0.10g)` |

三个项目放在一起正好构成一组**有意义的对照**：

- **同为 6 度区、同为公租房**（前进 vs 下沙）：可以比较「10 栋 / 1572 户」与「8 栋 /
  1114 户」在 Q-05 / Q-06（单栋户数、标准层交通规模）上的差异——规模越大，这两条
  指标的分数越低，而这是**计分区间**的问题、不是方案好坏的问题（详见
  [真实案例 README 第五节](../../data/schemes/qiantang-real/README.md)）。
- **同城不同烈度**（钱塘 6 度 vs 临平 7 度）：S-05 / S-06 的适用高度限值不同
  （6 度区剪力墙 140 m、7 度区 120 m），把同一套方案搬到临平，结构维度的判定与
  得分会变——这是演示「地方条件如何改变结论」最省事的做法。
- **规划条件齐全 vs 不齐全**（临平 vs 钱塘两个）：临平的容积率/密度/绿地率/限高
  可以直接照抄；前进一期能拿到用地面积、批准建筑面积（进而推出容积率 2.50）、
  绿地率 35%、栋数层数；下沙最小。三者正好演示「参数从多到少，系统分别怎么表现」。

**共同注意**：这些项目的**方案层数据（总平面、层数、户型、装配率）绝大多数没有
全文公开**。演示时请明确说明「项目层来自公开文件、方案层为团队演示数据」，
既守住了不许编造的底线，也避免被评委问到具体数值时无法作答。

## 四、还能从哪些渠道补「真实且可引用」的数据

1. **建设用地规划许可证 / 划拨决定书**（杭州市规划和自然资源局网站 → 审批结果公开）：
   给出面积、用途、文号，是引用最硬的来源。
2. **初步设计 / 总平面方案公示**（各区行政审批局「重要公告」栏目）：往往带
   总平面图与主要技术经济指标表（容积率、密度、绿地率、限高、户数）。
   前进公租房一期有此类公示页（2023-07-25），但**指标表通常在附件图片或 RAR 里**，
   需要人工打开核对，不能靠网页正文。
3. **装配式建筑专项公示 / 施工图审查信息**：可拿到装配率、预制构件类型，
   正是本系统 G-01/G-02/G-03 与 K-01/K-02 需要的字段。
4. **项目招标公告与工程量清单**：可拿到层高、楼栋数、层数、结构体系（但注意
   招标口径与规划口径可能不一致，引用时要注明来源类型）。

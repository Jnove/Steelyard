## 安全接入

`seed_mock.py` 在任何数据库初始化、删除和写入之前验证项目、方案和 What-if 父项；其默认替换同名项目行为仍须注意。

线上使用只追加脚本：

```powershell
uv run --project backend python scripts/publish_demo_cases.py
uv run --project backend python scripts/publish_demo_cases.py --apply --receipt backend/data/case-release/receipt.json
```

默认命令只预览，不访问线上。应用时新建明确命名的案例；完全相同的已发布数据可复用，有差异或额外方案则停止，绝不覆盖、删除原项目。可恢复中断的追加过程。每套案例发布后计算当前结果。

## 地区规则

54 条 GB 规则始终生效，34 条地方规则按项目省份和显式选择启用，共 88 条目录规则。当前 9 省为局部收录，其余省份空册不代表没有地方要求。

新建和编辑地块复用 SchemaForm。GB 在控件中始终可见且不可移除；未选地方册表示只用 GB。省份缺失、外省册或多省混用拒绝保存。API、Excel 和生成产物沿用同一元数据。

评估、读取结果、排序、Agent 解释与引用使用同一项目规则集合；地区或输入改变后旧证据返回 409，要求重新评估，其他项目不受影响。运行期 X- 规则保持兼容。地方评分重复计权未核定，当前不放行地方 metric。

辽宁建议条款改为 warning；重庆比例说明纠错；山西绿地类别和浙江全预制墙剪力比采用明确输入，缺失不猜。ZJ-S-05/06 仍有专业待核定标记。地区选择不等于历史有效时期、适用建筑类型或地方规范完整覆盖已验收。

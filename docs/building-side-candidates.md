# 建筑侧可补的方案层强制要求（国家层面标准）

> 这份清单是**给建筑组**的：条目、条号、数值与所需字段都来自国家层面标准的原文
> （GB / GB/T、JGJ 等行业标准、住建部部委文件），**不含地方标准与地方导则**。
> 我们（土木侧）只维护 `rules/` 里的 `S-*` / `K-*` 规则，**没有改动建筑侧的
> `C-*` / `Q-*` / `G-*` 文件**——是否落地、以什么口径落地，请建筑组决定。
>
> 检索时间：2026-10-13；原文来源见文末。

## 两条纠正性结论（会改变设计）

1. **GB 55016—2021 里没有分户墙 / 楼板的隔声量限值**。该规范第 2 章只有「室内噪声级限值」
   （表2.1.3、2.1.4）与「室内 Z 振级限值」（表2.1.5），隔声只有 2.2.1、2.2.2 两条原则性要求。
   真正的隔声量强条在 **GB 55038—2025 第6.1.2条**（卧室分户墙/楼板 DnT,w+C ≥50 dB、
   其他 ≥48 dB、楼板撞击声 ≤65 dB）。
2. **住宅目前已无「防火分区最大建筑面积」的强制限值**：GB 55037—2022 的公告明确废止了
   GB 50016—2014(2018年版) 第5.3.1条的强条效力，而 GB 55037 第4.3.16条只针对公共建筑。
   住宅安全出口数量应改用 **GB 55037—2022 第7.3.1条**（每层建筑面积 650 m² / 54 m / 疏散距离）判定。
3. **保障性租赁住房的适用性开关**：GB 55038 全部强条以「住宅建筑 / 套型」为对象；
   若保租房为宿舍型（非套型），套型条款适用性须专项判定，且防火按公共建筑要求
   （GB 50016 表5.1.1 注2）。**建议新增「套型形式（成套住宅 / 宿舍型）」字段**，
   作为所有住宅类规则的适用性开关。

## 二、加少量标量字段即可判定

建议字段：**标准层建筑面积**、**户门至最近安全出口最大疏散距离**、**室内噪声级（昼/夜）**、
**分户墙/楼板隔声量 DnT,w+C 与楼板撞击声 LnT,w**、**外墙/外窗 Rw+Ctr**、
**电梯轿厢净深/净宽与门净宽**、**是否设无障碍电梯**、**公共出入口外门净宽 / 平台净深 / 坡道坡度**、
**公共走廊净宽**、**栏杆净高（阳台 / 临空）**、**集中绿地面积与人均**、**是否临街**、
**声环境功能区类别**、**城区常住人口分级（≥50 万 / <50 万）**、**套型形式（成套住宅 / 宿舍型）**。

对应条目：GB 55016 表2.1.3/2.1.4/2.1.5（室内噪声级、Z 振级）、GB 55038 6.1.1~6.1.4（设备结构噪声、
分户隔声、外墙与外窗隔声、排水噪声）、4.2.4-3（轿厢尺寸）、4.2.7（无障碍出入口与外门、平台）、
4.2.1/4.2.2（公共走廊与楼梯）、4.2.8/4.1.15/4.1.16（栏杆与临空防护）、3.2.2（集中绿地与活动场地）、
3.2.6 表3.2.6（外墙面至道路边缘距离）、3.2.4/3.2.5（场地坡度与台地布局）、3.3.2/3.3.3（垃圾点与快递柜）、
4.1.1/4.1.4/4.1.6/4.1.13/4.1.14（套内最小面积与净宽）。

## 三、只能看平面 / 构造，做不成方案层规则

- GB 55016 2.1.3/2.1.4/2.1.5（室内噪声级、Z 振级——依赖构造与实测）、2.2.1/2.2.2（隔声原则）；
- GB 55019—2021 2.3.1/2.3.3/2.4.1/2.4.2/2.5.4/2.6.1/2.6.2/2.6.3（坡道与平台、门、候梯厅、轿厢尺寸）；
- GB 55037—2022 2.2.8-2（消防电梯前室面积与短边）、7.1.8-7（防烟楼梯间前室面积）、
  7.1.4（疏散净宽）；
- GB 55038—2025 4.2.1/4.2.2/4.2.7-2/-3、4.1.15、4.1.16、6.1.4、4.2.9（走廊、楼梯、栏杆、
  排水立管、地面防滑）。

## 六、方法学说明

- **检索代理读不了 PDF/Word**：会话内 `web_fetch` 对 `application/pdf`、`.docx` 返回
  "unsupported content type"，多数代理的 shell 也被沙箱阻断出网。
  本轮有两个代理自己写了 FlateDecode/CMap 抽取器绕过去，因此它们的条号可信度较高，
  但**入库前仍由我本地复核**（下载官方附件 → 去空格定位条款）。
- 因此每省进度取决于两件事：**官方是否免费公开正文**、**我们有没有对应字段**。
- 已核过的官方文件缓存在系统临时目录（`qinghai_residential.pdf`、`ningxia_guideline.docx`、
  `chongqing_baozhang.pdf`、`sichuan_energy.pdf`、`hebei_70y.pdf`、`shanxi_yiju.pdf`、
  `liaoning_haofang.pdf`、`hubei_gaopinzhil.docx`），核对脚本为 `verify_clause.py`。

## 七、收录纪律（重申）

1. **只收逐条核对过原文的**；`source` 写到条号/表号，可对照原文，并记核对日期；
2. **拿不到正文就空着**——空册是诚实状态，凭记忆或二手转述填数会毁掉整套规则的可信度；
3. **只有现行有效**的文本才能收（送审稿、征求意见稿、公示稿一律不收）；
4. **地方册并联国标**、不替换；同一件事国标与地方都有规定时，两条都会出现在结果里；
5. **市级文件要谨慎**：册的选择粒度是"省"，把某市的规定放进省册会让全省项目都套上它。
   建议下一步给册加"适用范围（省/市）"，或把市级条文放进独立的市级册。

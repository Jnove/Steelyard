### 2.4 运行期「自定义添加」的收尾

覆盖层（四类自定义 + 审计 + 回灌）的实现、验证与设计记录见
[自定义添加设计](design-custom-add.md)。**后端能力已完整**，剩下三件事：

- [ ] **前端设置页**：选项 / 权重模板 / 规则 / 字段的增删界面，以及留痕（`GET /api/custom/audit`）
      与导出（`GET /api/custom/export`）的展示。接口都已就绪，按分工不由后端负责；
- [ ] **接入真实登录身份**替换 `X-Operator` 占位：头可以伪造，**它不是权限判据**；
      当前靠"生产环境写接口一律 403"兜住。接入认证后只需换身份来源，
      留痕结构与接口都不用动；
- [ ] **养成"入库即删草稿"的习惯**：回灌（导出片段 → 粘进仓库 → 跑 CI）之后，
      要把界面上那份自定义内容删掉，否则它会以覆盖层的形式与内建内容**重复出现**；
      导出清单里已把这一步写成一条。

**两条不能忘的边界**：内建规则（`rules/*.yaml`）**不能引用自定义字段**（`check_rules`
是纯文件校验、看不到覆盖层），要一起入库；`rules/*.yaml` 里**不允许出现 `X-` 编号**
（`check_rules` 会报 `RUNTIME_PREFIX_IN_FILE`），回灌时必须换成维度前缀并顺延编号。

**土木侧规则的政策（沿用，勿在覆盖层里绕过）**：规则依据**只用国家层面标准**
（GB / GB-T、JGJ 等行业标准、住建部部委文件），不采用地方标准与地方导则；
建筑侧的 `C-*` / `Q-*` / `G-*` 由建筑组维护，本功能未改动它们。

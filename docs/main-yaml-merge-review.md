# 专业 YAML 与 PR 合并评审

日期：2026-10-13。审查对象：main 的建筑提交 [9923b3b](https://github.com/Jnove/Steelyard/commit/9923b3b24d0b8af4f473f3016eb81c83007c2ea7)，以及土木 [PR #8](https://github.com/Jnove/Steelyard/pull/8) 的最终提交 `585a26a`。前端玻璃界面与 Three.js 自动旋转在 `bb3a54e` 已提交，集成保留该历史。

## 审核结论

PR #8 的 CI 修复有效：最终提交的前后端检查通过，本机合并后原始版本 **486 个后端测试通过**。其有效改动包括结构 S-01～S-14、参数字段、派生高宽比、生成类型 / Schema / Excel，以及将占位状态绑定的测试改为合成夹具。自定义字段 / 规则运行时覆盖功能已被后续提交撤回，不在最终 diff 中。

但原 PR 的权重适配删除了实际可选的设计角色，只在注释里保留；离线计算快照未更新，前端还沿用旧规则、旧字段和旧权重。绿灯不足以说明这些用户路径已经适配。

### 原文抽查

- 电梯条件及楼板适用描述：[北京市规划自然资源部门发布的 GB 55038-2025 摘录](https://ghzrzyw.beijing.gov.cn/biaozhunguanli/bzzl/202506/P020250609570099619169.pdf)，PDF 第9～10页。电梯触发量是入户楼面高度，不是建筑总高。
- 不规则项去重：[岳阳住建部门公开附件](https://jsj.yueyang.gov.cn/uploadfiles/201901/20190118094941987.pdf)，附录 E 附件1 表2，PDF 第119页；本轮读取了注释中的同类项不重复计数要求。
- [福建住建厅转发通知及附件](https://zjt.fujian.gov.cn/hygl/kxjs/kcsj/201506/t20150630_2886035.htm)用于核对建质〔2015〕67号来源。

上述抽查与代码边界测试不等于逐条专业核定，也没有把原文接入 T10 检索库。

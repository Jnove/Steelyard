## 各成员的近期交付

- **Jnove**：技术集成、界面交互衔接、真实模型验收、部署、技术说明汇总和最终版本核对。
- **建筑**：主案例的合规、居住品质、绿色相关规则及出处；政府 / 保障房平台、住户偏好的说明；案例、术语与结论核对。
- **土木**：主案例的结构相关指标、施工友好与工友安全规则及理由；施工总包、开发企业偏好的说明；参数修改前后结果的专业复核。
- **工业设计**：示例体验路径、看板信息层级、结论旁操作、架构图与视频制作，组织一次非专业用户走查。基于现有 Ant Design / ECharts 页面推进。

建筑与土木可以先交含来源的规则表，由 Jnove 转换并接入；能直接提交 YAML 的按 [规则指南](rules-guide.md) 操作。新增字段统一由技术组维护模型与生成产物。

角色偏好优先核定主案例实际采用的视角；其他模板继续标明待核定，不以一次完成全部角色和指标为初筛前提。

## 初筛范围与验收

保留一个统一地块、3–5 个候选方案的主案例，走通规则检查、四维比较、角色或权重调整、计算追溯、一次 What-if 和报告。所有讲解采用系统实际返回的结果，不预设某方案必须胜出或角色切换必须换位。

提交前检查：

1. 非专业用户能说清目标用户、核心取舍、推荐依据和 AI 的作用，并能独立完成主路径。
2. 实际展示的规则、假设与角色偏好都有清楚来源和适用范围；未核定内容继续标记，示例数据不得充当工程验证结果。
3. 明确区分真实模型、FakeLLM 与离线模拟；模型输出、确定性计算和最终报告口径一致，加载、错误及取消状态可理解。
4. 四项材料对应同一版本、同一案例和同一能力范围，Demo 与源码包的入口及运行说明可用。

**初筛后再推进**：完整 T10 检索、更多规范与指标、需要新增字段的评价、大规模界面重构、尚未建立依据的造价或碳排估算、答辩 PPT。通过后按通知给出的约 5–6 天重新排序，优先修复初筛反馈与关键体验问题。
